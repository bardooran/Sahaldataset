# Frozen evaluation data

This area is for frozen benchmarks used to measure SahalNLP or Sahal AI.

A benchmark should record:

- task and scoring rules;
- data source and licensing;
- label/review process;
- freeze date and commit;
- system/version measured;
- whether answers have been inspected during development.

Training and evaluation must remain separate. Once benchmark answers influence implementation, the benchmark becomes a regression/diagnostic set and must not be called unseen.
